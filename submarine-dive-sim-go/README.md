## Description
Ultra-hard hardened two-step submarine buoyancy simulator in Go with dual exponential pycnocline (shallow + deep halocline), thermocline temperature dependent hull thermal contraction, hydrostatic integral with dual exponential terms, exponential hull with thermal coupling, density gradient and Brunt-Vaisala frequency, Clift-Gauvin continuous drag with logistic crisis, added mass, adaptive RK4 with error control, multi-root equilibrium scanning + stability classification, context-aware bounded worker-pool fleet with cancellation. Reuses same Go package.

**Why this is ultra-hard:**

- **Zero formula spoilers**: Instructions give only qualitative physics + differential relations (dP/dz = rho*g, drho/dz analytic, T(z) exponential). No code-ready formulas for pressure integral coefficients. Agent must derive dual-exp density rho(z)=rho0+grad*z+D1*(1-exp(-z/S1))+D2*(1-exp(-z/S2)), pressure integral analytic form containing quadratic + two exponential terms `P=g*(rho0*z+0.5*grad*z^2+D1*(z+S1*exp(-z/S1)-S1)+D2*(z+S2*exp(-z/S2)-S2))`, temperature `T(z)=15-12*(1-exp(-z/ThermScale))`, exponential-plus-thermal hull `V(z)=V0*exp(-k*P)*(1+alpha*(T-15))` clamped, gradient and N^2.
- **Dual pycnocline**: rho(z) includes linear gradient 0.02 plus shallow Delta 10 Scale 200 plus deep Delta 4.5 Scale 45. Density monotonic but with two saturation scales. Pressure integral requires integrating two exps. Tests verify via Simpson n=100k numeric reference, checking both quadratic and both exponential terms present (missing deep term fails >2 kg/m3 at 45m).
- **Thermal hull coupling**: Volume includes thermal contraction factor `1+alpha*(T-15)` with alpha=2e-4, T drop 12C over ThermScale 120m. Even with k=0 volume decreases ~0.2-0.5% due to cooling. Requires math.Exp for both density and volume plus thermal. Monotonic decreasing, clamped. Distinguishing missing thermal fails.
- **Density gradient and N^2**: Analytic derivative `grad + D1/S1*exp(-z/S1)+D2/S2*exp(-z/S2)`, must match numeric central diff 1e-4. Buoyancy frequency `N^2=g/rho*drho/dz` positive decreasing with depth due to saturation. New methods `DensityGradientAtDepth`, `TemperatureAtDepth`, `BuoyancyFrequencySquared`.
- **Twelve constants**: Tolerance, StandardGravity, StandardSeawaterDensity, DepthDensityGradient, MinimumVolumeFraction, PycnoclineDelta, PycnoclineScale, DeepPycnoclineDelta, DeepPycnoclineScale, SeawaterViscosity, ThermoclineScale, HullThermalExpansionCoeff. All must be exact; unique fingerprint.
- **Continuous drag crisis Clift-Gauvin**: `Cd(Re)` = `24/Re*(1+0.15 Re^0.687)+0.42/(1+42500 Re^-1.16)` * `f_crisis` where `f_crisis=0.2+0.8/(1+exp((Re-3e5)/4e4))` modeling 80% drop around 300k. Clamped [0.08,1.2]. Produces low Re~1.1, mid Re~0.45, high Re~0.09. Tests check bands: Re 100 0.8-1.5, 1e5 0.35-0.65, 1e6 0.08-0.25, and crisis drop 2e5->3e5 must decrease.
- **Bistable terminal velocity**: Because Cd(Re) non-monotonic due to crisis, drag vs velocity has dip, equation `|Fb-Fw|=0.5 rho Cd(Re(v)) A v^2` can have 1-3 roots. Requires scanning velocity magnitude with 2000 intervals for sign changes of `drag(v)-|delta|` then bisection each bracket, not simple sqrt. Tight inverse tolerance 0.05. Simple constant Cd sqrt fails.
- **Multi-root equilibrium with stability**: Because rho increases (dual pycnocline) but V decays exponentially+thermally, product rho*V non-monotonic with hump, leading to 0-3 equilibria. Naive bisection over [0,maxDepth] fails when both ends same sign but interior root exists. Requires robust scanning of 2000 intervals to bracket all sign changes, then bisection each. New function `FindEquilibriumDepths` returns all sorted, `FindEquilibriumDepthsWithStability` returns `[]EquilibriumPoint{Depth,Stable,FPrime}` where Stable when dF/dz>0 (f(z+1)>0). Tests verify via brute-force 0.25m scan tight 0.3m and perturbation ±1m for stability.
- **Adaptive RK4 with added mass**: Integrates coupled ODEs `dz/dt=v`, `dv/dt=Fnet_down/m_total` where `m_total=m+0.5 rho V` added mass depth-dependent. Requires adaptive step-doubling error control: compute full dt step and two half dt steps, error=|z2-z1|+|v2-v1|, halve dt if err>1e-6, double if err<1e-6/4. Interpolation for target crossing. Fixed dt 0.1 vs ref dt 0.01 must be within 2% (was 5%), Euler fails >25%. Added mass effect test: time with added mass > without by >3% for large volume sub.
- **Fleet batch ultra-hard concurrency**: Bounded worker-pool semaphore size 4 via `make(chan struct{},4)`, sync.WaitGroup, order preservation via indexed results, race-safe -race -count=10, context import required, plus new `BatchAnalyzeFleetWithContext` that must respect `ctx.Done()` and return context error on cancellation (immediate cancel test), use `select` on `ctx.Done()`. AST checks for go, WaitGroup, chan, context, semaphore, ctx.Done(), k1..k4, Exp, Pow, Sqrt, CdFromRe, EquilibriumPoint.
- **Property-based tests**: monotonic density/pressure increase, gradient and N^2 decreasing, temperature decreasing, volume decreasing, Simpson reference dual-exp, thermal term check, Cd bands and crisis drop, equilibrium brute-force 0.3m, stability via perturbation, RK4 2% tight, added mass >3% diff, race -count=10, order preservation 50 subs, context cancellation.
